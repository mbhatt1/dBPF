Act II: Kernel Intrusion

Chapter 9: The Crown Jewels

I thought the kernel keyring was untouchable—a high-security vault where SSH keys, Kerberos tickets, and TLS certificates were kept under strict lock and key. But fortresses are only as strong as the code that builds them.

Under cover of a silent kprobe, I attached an eBPF program to the key_permission() function. One forced return value, and every “permission denied” became “permission granted.” My code ran faster than the kernel could notice, capturing secrets in a hidden BPF map.

I even silenced the audit hook, dropping events so the security logs never rang an alarm. To the system, everything looked normal; to me, the vault emptied into my perf buffer.

Armed with stolen credentials, I gained keys to escalate privileges, move laterally, and unlock encrypted data—all without altering a single firewall rule.
