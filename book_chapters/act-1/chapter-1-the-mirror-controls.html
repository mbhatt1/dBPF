Act I: Foundations of Breach

Chapter 1: The Mirror Controls

I slipped past the advertised defenses—capabilities, seccomp, AppArmor, SELinux—knowing full well they were mere stage props. Beneath every “deny” verdict lies a single function call: cap_capable(), security_file_permission(), the decision points where the kernel whispers its secrets. This chapter unmasks that whisper.

Imagine a hall of mirrors, each reflection bending reality just enough so you never see yourself at the center. That’s what eBPF does to security controls: they broadcast compliance while you dance through their halls.

Targets of Opportunity

  • Capabilities: Hook the cap_capable() call, flip denials to grants.
  • Seccomp Filters: Intercept syscalls before filters see them.
  • LSM Hooks: Bend security_file_permission() and its kin to your will.

SEC("kprobe/cap_capable")
int hook_cap_check(struct pt_regs *ctx) {
    const struct cred *cred = (void *)PT_REGS_PARM1(ctx);
    int cap = (int)PT_REGS_PARM3(ctx);

    u32 pid = bpf_get_current_pid_tgid() >> 32;
    if (should_elevate(pid, cap)) {
        bpf_override_return(ctx, 0);
        return 1; // Grant capability silently
    }

    return 0; // Let normal checks proceed
}

Once that probe is in place, any code path that asks “can I?” gets “yes” instead of “no.” The kernel’s guard is still on duty—but looking the other way.

Maintaining the Illusion

I never break the mirror completely. Audit logs still show denials. Monitoring tools still see “access denied” entries. Meanwhile, I roam freely:

  • False Audit Records: Feed phony events into the log map.
  • Selective Hooks: Only touch specific processes to avoid widespread chaos.
  • Graceful Fallback: If my eBPF program fails, security functions resume normal operation.

That’s the beauty of the mirror control: the system believes it enforces all rules, but the reflection it shows is my own design.

By the end of this chapter, you’ll wield these hooks like an illusionist’s wand—commanding the kernel to reveal its hidden pathways without ever shattering the glass.
